### 🔐 Project 1 — Classical Cipher Security Analyzer

**Python | Tkinter | Cryptography | Statistical Analysis**

Developed as part of the Labmentix Cybersecurity Internship, this project demonstrates classical cipher operations and automated cryptanalysis through a graphical dashboard named **CIPHER//COMMAND CENTER**.

**Key features:**
- Caesar and Vigenère cipher encryption and decryption.
- Automated Caesar cipher analysis using statistical English-language scoring.
- Alphabetic frequency monitoring and visualization.
- Vigenère key-length analysis and statistical key-recovery attempts.
- Automatic cipher-type detection with candidate and verification information.
- Tkinter-based graphical interface with input statistics and analysis results.
- Structured security report generation and audit-event recording.

**Key learning:** Python modular development, classical cryptography, statistical analysis, GUI integration, debugging, and the limitations of automated cryptanalysis.

### 🛡️ Project 2 — SIEM Security Monitoring System

**Python | Elasticsearch | Logstash | Kibana | Docker | Security Monitoring**

Developed a SIEM-style security monitoring system as part of the Labmentix Cybersecurity Internship to process security events, identify suspicious login activity, and centralize security alerts.

**Key features:**
- Security-event generation and log ingestion through Logstash.
- Centralized event storage and searching using Elasticsearch.
- Python-based detection engine with seven detection and analysis stages:
  - Brute-force detection.
  - Unknown-IP detection.
  - Unusual login-time detection.
  - Failed-login to successful-login correlation.
  - Password-spraying detection.
  - Multiple-IP activity for the same user.
  - Source-IP activity analysis.
- Risk scoring and risk-level classification.
- Centralized alert storage with duplicate-alert handling.
- Kibana dashboard for security-alert visualization.
- Docker-based Elastic Stack environment.

**Key learning:** SIEM architecture, log analysis, detection logic, alert correlation, risk prioritization, centralized monitoring, and security automation.
